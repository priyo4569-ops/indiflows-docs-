# IndiFlows Documentation (Mintlify) 📖⚡

IndiFlows উইন্ডোজ ডেস্কটপ এবং অ্যান্ড্রয়েড মোবাইল অ্যাপ্লিকেশনের পূর্ণাঙ্গ ডকুমেন্টেশন পোর্টাল।

---

## 🚀 লোকাল প্রিভিউ চালানোর নির্দেশিকা

১. টার্মিনালে `docs` ফোল্ডারে প্রবেশ করুন:
```bash
cd docs
```

২. মিন্টিফাই ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
# অথবা:
npx mintlify dev
```

৩. ব্রাউজারে স্বয়ংক্রিয়ভাবে ওপেন হবে অথবা ভিজিট করুন:
```
http://localhost:3000
```

---

## 🛠️ বিল্ড ও ভ্যালিডেশন
ডকুমেন্টেশনে কোনো ভাঙা লিংক বা সিনট্যাক্স এরর আছে কিনা যাচাই করতে রান করুন:
```bash
npm run validate
```

---

## 📁 ডকুমেন্টেশন স্ট্রাকচার

- `docs.json` - মিন্টিফাই কনফিগারেশন ও সাইট নেভিগেশন
- `index.mdx` - ডকুমেন্টেশন হোমপেজ
- `getting-started/` - পরিচিতি, কুইকস্টার্ট ও সিস্টেম আর্কিটেকচার
- `windows/` - উইন্ডোজ ইনস্টলেশন, গ্লোবাল শর্টকাট, ফ্লোটিং পিল, ভয়েস টাইপিং, লিগ্যাসি ফন্ট ও সেটিংস
- `mobile/` - অ্যান্ড্রয়েড ইনস্টলেশন, পারমিশন, ফ্লোটিং পিল ওভারলে, অটো-পেস্ট, ভাষা ও একাউন্ট
- `cloud-security/` - ক্লাউডফ্লেয়ার STT ওয়ার্কার, Sarvam AI ও Supabase ডাটাবেজ
- `troubleshooting/` - উইন্ডোজ ও মোবাইল ট্রাবলশুটিং এবং সাধারণ প্রশ্নোত্তর (FAQ)
